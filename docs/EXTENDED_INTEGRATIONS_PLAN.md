# Bounded local extensions

The approved local completion execution includes inert import capability. Sources remain local material; they never become verified facts without review. No external service is activated by these features.

| Child | Implemented local capability | Remaining boundary |
| --- | --- | --- |
| X01 PDF | Exact original, bounded text-only child process, deterministic page ranges, new extracted version; empty/password/page-limit statuses | No OCR, rendering, passwords, actions or external data fetching |
| X02-A n8n export | Supplied JSON structural inventory, node/connection validation, credential references withheld from context, hardcoded-secret rejection; original preserved | No live n8n connection/import/run/publish or workflow modification |
| X02-B selected directory | Browser-selected FileList preview, text/Markdown allowlist, hidden/build/dependency exclusions, 100-file/10 MiB cap, partial report and archive-batch action | No unattended traversal or arbitrary server disk path |
| X02-C selected conversation | Explicit supported JSON and selected turns; speaker/time retained, omitted turns not stored, full-export digest only | No background chat capture or arbitrary account/archive ingestion |
| X02-D comparison | Owner can inspect alternative same-subject proposals with statuses/evidence and explicitly supersede | No automatic contradiction verdict, duplicate merge or canonical winner |
| X02-E trace/batch | Actual selected result IDs, revisions, budget/latency/query digest; bounded folder-import report and archive operation | No invented agent reasoning or bulk permission bypass |

Supported conversation input is `{"format":"atlas-selected-conversation-v1","turns":[{"id":"turn-1","role":"user","timestamp":null,"text":"Selected source material"}]}`. Roles are `user`, `assistant`, `system`, `tool`; timestamps are ISO strings or null. The owner selects the turns in the UI. The saved original is the selected excerpt, not the omitted full archive; the original input file is never edited. Derived claims remain candidates.

The following children remain separate operational scopes in the approved plan:

- **X02-F scheduled backups:** after a verified restore, choose an explicit destination, retention, cadence and notification policy. Prepare an automation through the supported app tool only when scheduling is specifically requested. Do not install startup jobs implicitly.
- **X02-G GitHub/source sync:** identify the exact repository/branch and read-only selection, connector/credential, refresh policy and conflict handling before implementation. Local planning does not authorize remote writes or commits.
- **X02-H remote MCP/multiple devices:** define hosting, OAuth, revocation and filesystem access boundaries. Loopback credentials must never be reused publicly; no tunnel or public deployment is part of this release.
- **X02-I temporal/analytics/spatial views:** base future views on actual recorded history. Keep measured performance and privacy budgets. Embeddings/model APIs remain excluded by project instruction.

The n8n adapter follows the automation workspace's access/export/security instructions in local JSON mode. Its static inventory is distinct from live node validation and execution evidence. It does not create or edit any automation project.
